Compile & Run Any Source File

FastCR is a lightweight Bash command that eliminates repetitive compile-then-run workflows. Support for 11 programming languages with millisecond timing.

Installation

Linux/macOS

# Clone and install
git clone https://github.com/Quillpy/FastCR.git
cd FastCR/linux
chmod +x install.sh
./install.sh

The installer places cr in /usr/local/bin or ~/.local/bin

Windows (PowerShell)

# Run in PowerShell
git clone https://github.com/Quillpy/FastCR.git
cd FastCR\windows
powershell -ExecutionPolicy Bypass -File .\install.ps1

Installs cr.ps1 and a handy cr.cmd shim

Verify installation:

Verify
cr --help
